# 复盘侠 · 教学智能体比赛演示版

这是一个**纯前端、可直接部署到 GitHub Pages** 的中文在线教育智能体比赛演示应用。

## 主要特点

- 无需服务器、无需数据库、无需 npm 构建
- 上传到 GitHub 后即可通过 GitHub Pages 在线访问
- 支持电脑与手机
- 学习记录保存在当前浏览器 localStorage
- 内置 6 个明确标注的比赛演示案例
- 支持四类复盘：错题、编程纠错、实训/项目、考试/阶段学习
- 支持完整闭环：输入 → 诊断 → 追问 → 分级提示 → 修改 → 迁移练习 → 复盘卡 → 保存 → 复习任务
- 复盘档案、专项练习、今日复习、学习报告、教师演示工作台、题库均可实际操作
- 演示数据与真实本地记录分离
- 未执行代码时明确显示“仅静态分析，未实际执行”
- 支持 Markdown / JSON 导出和打印

## 重要限制

这是纯 GitHub Pages 比赛版，因此：

1. 不具备服务器级多用户登录与数据隔离。
2. 教师工作台用于展示审核闭环，并非真实服务器教师账号。
3. 数据仅保存在当前浏览器；更换设备不会自动同步。
4. 代码纠错为静态分析，不执行学生代码。
5. 未接入后端知识库/RAG和离线通知。
6. 不建议把长期有效的大模型 API Key 直接写在纯前端代码中。

这些限制在应用“设置与帮助”页面也有明确标注，避免虚构能力。

## 本地运行

最简单：直接双击 `index.html`。

也可用任意静态服务器。

## GitHub Pages 部署

1. 登录 GitHub，新建仓库，例如 `fupanxia`。
2. 将本项目里的所有文件上传到仓库根目录：
   - `index.html`
   - `styles.css`
   - `data.js`
   - `app.js`
   - `README.md`
3. 打开仓库 **Settings**。
4. 左侧选择 **Pages**。
5. `Build and deployment` 下的 `Source` 选择 **Deploy from a branch**。
6. Branch 选择 `main`，目录选择 `/ (root)`。
7. 点击 **Save**。
8. 等待 GitHub Pages 发布完成后，会显示在线地址，一般形如：
   `https://你的GitHub用户名.github.io/fupanxia/`
9. 把这个网址发给评委即可。

## 建议评委演示路线

1. 打开网站
2. 点击左侧“比赛演示”
3. 选择“Python循环边界错误”
4. 回答智能体追问
5. 点击“给我一点提示”或“我想自己试试”
6. 重新作答
7. 完成迁移练习
8. 生成复盘卡
9. 打开“今日复习”与“学习报告”
10. 进入“教师工作台”查看并修改审核记录

## 文件说明

- `index.html`：主页面
- `styles.css`：响应式视觉样式
- `data.js`：课程、演示案例、题库、资料
- `app.js`：应用逻辑、本地存储、复盘流程、统计和教师审核
